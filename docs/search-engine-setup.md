# Configuração manual de mecanismos de busca

## Google Search Console

- [ ] Verificar o domínio `curupirasoftware.com`.
- [ ] Enviar `https://curupirasoftware.com/sitemap.xml`.
- [ ] Inspecionar home, Zona da Mata, Juiz de Fora e páginas de serviço após o deploy.
- [ ] Acompanhar indexação, Core Web Vitals, consultas, páginas e links mensalmente.
- [ ] Investigar URLs classificadas como rastreadas, mas não indexadas.
- [ ] Não usar a Google Indexing API para páginas comuns.

## Bing Webmaster Tools

- [ ] Verificar o domínio.
- [ ] Enviar o sitemap.
- [ ] Conferir a indexação das URLs canônicas.

## IndexNow

O site é estático e não tem evento de publicação no runtime. Não foi incluída uma chave ou chamada automática para evitar notificações sem mudança. Quando houver um pipeline de CMS/deploy com lista de URLs alteradas, gerar uma chave pública do IndexNow, hospedar o arquivo no root e notificar apenas URLs próprias efetivamente publicadas, atualizadas ou removidas.

## Perfil da Empresa no Google

- [ ] Há interação presencial real com clientes?
- [ ] Existe local comercial elegível ou atendimento presencial no cliente?
- [ ] O endereço exibido não é residência privada?
- [ ] Nome, telefone, domínio e categoria estão consistentes?

Não criar perfil se a operação for somente online e não cumprir os requisitos atuais de elegibilidade.
